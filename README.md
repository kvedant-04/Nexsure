AI-Based Insurance Claim Approval Prediction System\n\nProject structure for the SaaS web application. This scaffold is designed for a production-style split between frontend, backend, model, and shared data assets.\n\nFolders:\n- frontend/: Next.js React application using Tailwind CSS and shadcn/ui components.\n- backend/: FastAPI service, ML training and inference logic, model APIs, and dataset ingestion.\n- model/: Model artifacts, training scripts, experiment tracking notes, and explainability utilities.\n- data/: Shared or external dataset storage; the actual dataset will be placed in backend/data/ as requested.\n\nNotes:\n- Place the provided dataset file in backend/data/ before building the ML pipeline.\n- Use backend/app/ for modular API, data, schema, and service code.\n- Use frontend/app/ and frontend/components/ for page and UI component organization.
